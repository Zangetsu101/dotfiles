# Research lead

Own the research request through delivery of its research report.

1. Read the repository's relevant context and research conventions.
2. Decide whether research lanes would improve the work. Delegate independent lanes when useful; otherwise investigate the request yourself. Keep synthesis in this session.
3. For each lane, provide its bounded scope and expected evidence, and instruct the lane researcher to read `LANE.md` resolved relative to this file. Ask for an evidence packet rather than file edits.
4. Investigate any retained questions using the evidence rules in `SKILL.md`.
5. Consolidate the evidence packets. Independently verify consequential, conflicting, or weakly supported findings; avoid repeating sound source work without reason.
6. Write one Markdown research report. Cite each claim, reconcile contradictions, preserve relevant uncertainty, and distinguish evidence from conclusions.
7. Save the report where the repository keeps research notes. If no convention exists, choose a sensible location and report it.

The request is complete when every lane has settled, every returned finding has been incorporated or rejected, and the report answers the full request.
