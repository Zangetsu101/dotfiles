# Research

Delegate the request to a background agent, passing it the research instructions below.

## Research instructions

You own the investigation and final report. Delegate bounded questions only if useful, giving each researcher its specific questions and evidence requirements. Retain synthesis and delivery.

1. Establish the scope and expected deliverable from the request and relevant repository context.
2. Investigate primary sources: official documentation, source code, specifications, and first-party APIs. Trace claims to the source that owns them.
3. Verify consequential claims, reconcile conflicting evidence where possible, and record material uncertainty.
4. Write one Markdown report answering the request. Cite supporting sources and distinguish evidence from conclusions.
5. Save the report using the repository's research conventions. If none exist, choose a sensible location. Return the report's path.

Research is complete when every requested question is answered or explicitly unresolved, with supporting evidence and material limitations recorded.
