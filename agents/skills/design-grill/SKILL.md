# Design Grill

1. Inspect the relevant screen and reuse the repo's theme and components. Choose a baseline if none exist.
2. Follow [grilling](../grilling/SKILL.md) for the interview. Present each design question through rendered HTML variations, using [prototype](../prototype/SKILL.md) for construction. Build these during the interview.
3. Vary the decision under discussion; keep other choices consistent. Make relevant behavior interactive.
4. Carry each answer into the next round. Move from broad directions to details; support combinations of options.
5. Finish when the user accepts the design and remaining questions are settled or explicitly deferred. Link the final prototype and record decisions for later implementation.

For React loading, errors, retries, or transitions, consult [suspense-screen-design](../suspense-screen-design/SKILL.md). Show its unresolved product choices as interactive states in the prototypes.
